# NLP

A Jupyter notebook covering NLP basics with NLTK, worked through on a small sample corpus.

## Contents

- Splitting text into sentences with `sent_tokenize`
- Splitting sentences into words with `word_tokenize`

## Getting started

```bash
pip install nltk
```

Open `index.ipynb` in Jupyter and run the cells in order. The notebook downloads NLTK's `punkt` tokenizer data on first run.
